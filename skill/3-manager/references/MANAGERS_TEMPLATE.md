# 현업 담당자 역할 프로파일링 및 거시->미시(Funnel) 질문 전략 (`sk/work/MANAGERS.md`)
> **생성 스킬**: `3-manager`
> **목적**: `sk/work/INBOX.md`와 `README.md`의 현업 담당자(1명 또는 2명 이상) 정보를 바탕으로, 이어지는 `4`·`5`·`6`번 스킬에서 **거시적 질문(누가·어떻게·얼마나 자주 쓰는지, 어떤 가치를 창출할지)부터 미시적 질문(데이터 근거 예외 처리·허용 임계값), 최종 서면 합의까지** 체계적으로 소통할 질문 도메인을 매핑한다.

## 1. 과제 내 현업 담당자 구성 유형 판별
- **담당자 구성 형태**: `[단일 담당자 (1명)]` 또는 `[복수 담당자 (2명 이상)]`
- **운영 방침**:
  - 담당자가 **1명**인 경우: 한 번의 DM 안에서도 반드시 **`[거시 맥락(이용 주체·빈도·핵심 가치·운영 상황)] -> [미시 기준(데이터 이상치·수치 임계값)]`** 순서로 질문을 배치한다.
  - 담당자가 **2명 이상**인 경우: 각 담당자의 전문 도메인(비즈니스/시장분석 vs 교육/현장/기술)에 맞춰 거시·미시 질문을 분리 배정한다.

## 2. 담당자별 프로필 및 질문 도메인 매핑

### 담당자 1 프로필
- **이름 / 직함 / 부서 (업무 역할)**: ...
- **보유한 현업 지식 영역 (`README.md` 근거)**: ...
- **단계별 질문 배정 영역 (거시 -> 미시 -> 합의 흐름)**:
  - **[1단계 거시 질문 (서비스 이용 맥락 · 창출 가치 · 운영 환경)]**: 현행 업무에서 가장 곤란했던 병목, 결과물과 화면을 **누가·언제·얼마나 자주 사용하는지(다수 운영자 동시 수정 여부 및 데이터 갱신 주기 포함)**, 이번 서비스로 어떤 핵심 가치를 창출하면 좋을지, 꼭 챙길 것과 제외해도 되는 경계 확인
  - **[2단계 미시 질문 (데이터 근거 예외 처리 · 수치 임계값)]**: 데이터 분석(`EDA_REPORT.md`, `EDA_SUPPLEMENT.md`)에서 발견된 테이블 간 차이·특이값 처리 기준(`IC-#`), 최적화 판단 기준의 구체적 수치 상한선(최대 허용 시간/거리/오차/중복제한 등, `UG-#`) 및 역할별 화면 필수 표시 지표 확인
  - **[3단계 최종 서면 합의 (`6`번 스킬)]**: `문제 / 만들 것 / 제외할 것(Cut List) / 성공 기준 / 제약 조건` 5줄 요약 컨펌

### 담당자 2 프로필 (단일 담당자 과제일 경우 `해당 없음` 표기)
- **이름 / 직함 / 부서 (업무 역할)**: ...
- **보유한 현업 지식 영역 (`README.md` 근거)**: ...
- **단계별 질문 배정 영역 (거시 -> 미시 -> 합의 흐름)**:
  - **[1단계 거시 질문]**: 해당 담당자 관점의 주요 이용자, 활용 빈도, 핵심 창출 가치 확인
  - **[2단계 미시 질문]**: 해당 담당자 소관 데이터 제약·예외 기준, 시나리오 테마 및 화면 필수 지표 확인
  - **[3단계 최종 서면 합의]**: 해당 담당자 소관 스펙 요약 컨펌

## 3. 현업 담당자 소통을 위한 거시 -> 미시(Zoom-Out to Zoom-In) 3원칙
1. **거시에서 미시로 좁혀 가는 깔때기(Funnel) 흐름 준수**:
   - 처음부터 지엽적인 컬럼값만 묻지 말고, **1) 현업의 가장 큰 불편과 창출할 핵심 가치 -> 2) 누가·어떻게·얼마나 자주 쓰는지(운영 환경·동시성·권한 경계) -> 3) 데이터에서 발견한 구체적 수치와 허용 임계값** 순서로 질문한다.
2. **구현 방법 대리 질문 금지 및 제안형 질문 작성**:
   - "어떻게 구현할까요?", "어떤 기능을 넣을까요?" 같은 개방형 질문 대신, **`[현업 맥락 또는 데이터 발견 사실] + [운영 기준·가치 우선순위·허용 임계값 질문] + [별도 기준 없을 시 적용할 우리의 추천 기본안]`** 구조로 질문한다.
3. **최적화 가치 충돌 시 우선순위 및 정량 임계값(Threshold) 확인**:
   - 운영 효율(차량 대수/예산/장비 가동률)과 이용자 가치(편의/품질/안전)가 충돌할 때 현업이 더 중시하는 가치와 최대 허용 상한선(시간/거리/오차 등)을 함께 확인한다.
